# Instrucciones y ayuda para las prácticas

## 1. Git

Seguimos las instrucciones de w3schools.com para configurar Git y GitHub (https://www.w3schools.com/git/).

### Lo básico:

0. Clonar el repositorio (sólo la primera vez) a tu ordenador:

```{bash}
git clone git@github.com:compmaths/py-math-lab.git
```
1. Sincronizar con  los cambios de github

```{bash}
git pull
```

2. Ver el estado del repositorio 

```{bash}
git status
```

3. Ver el historial de versiones 

```{bash}
git log
```

3. Añadir un fichero a control de versiones (uno ya existente)

```{bash}
git add (nombre del fichero)
```

4. Cuando ya has hecho algo, cremaos una nueva versión local del fichero

```{bash}
git comit -am "mensaje breve que identifica el cambio"
```

5. Subir las versión a github

```{bash}
git push 
```
